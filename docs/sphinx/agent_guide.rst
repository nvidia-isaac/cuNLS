################################################################################
Guide for Agents
################################################################################

The guide below ships inside the ``pycunls`` package (``python -m pycunls
guide`` prints it), so a coding agent that only has the installed wheel finds
it. It is the shortest path from a task to a correct solve: which entry point
to use, the conventions that cost a turn when missed, what to check after a
solve and how to fix the common failures.
